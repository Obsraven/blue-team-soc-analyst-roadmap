# Blue Team & SOC Analyst Roadmap 2026

**Free Defensive Security Learning Guide — From Logs to Detection, Investigation, Response, and Purple Team Validation**

This project is a public learning roadmap for people who want to begin or strengthen a path into SOC analysis, blue teaming, detection engineering, incident response, threat hunting, and purple teaming.

The goal is not to memorize hundreds of tools. The goal is to understand systems, collect useful telemetry, investigate evidence methodically, build reliable detections, respond safely, and continuously improve defenses.

## What the guide covers

- Networking, Windows, Linux, identity, and scripting foundations
- Endpoint, identity, network, cloud, and application telemetry
- A repeatable SOC alert-investigation workflow
- Modern defensive tools organized by the questions they answer
- Lightweight Wazuh / Security Onion lab architecture
- Detection engineering with MITRE ATT&CK and Sigma
- Incident response and DFIR fundamentals
- Threat hunting and Purple Team validation
- Free and practical training resources
- A 90-day starter sprint
- Portfolio projects that demonstrate real defensive reasoning

## Core methodology

**See → Decide → Act → Improve → Retest**

A useful defensive workflow is:

1. Understand the behavior or protocol.
2. Instrument the environment so the behavior can be observed.
3. Investigate the evidence.
4. Explain what happened and how confident you are.
5. Improve telemetry, detections, playbooks, or controls.
6. Retest the same behavior.
